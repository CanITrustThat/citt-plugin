description: Search the decompiled app corpus by literal string or regular expression
argument-hint: QUERY [--regex|--literal] [--case-sensitive] [--corpus C] [--package PKG] [--build-id ID] [--count] [--limit N] [--cursor C] [--all] [--out FILE.csv] [--json]
allowed-tools: Bash(${CLAUDE_PLUGIN_ROOT}/skills/citt/scripts/citt:*), Read
---

Run `${CLAUDE_PLUGIN_ROOT}/skills/citt/scripts/citt code-search $ARGUMENTS` and relay the result.

Search every indexed decompiled build for a string (`--literal`, the default) or a regular expression (`--regex`); `--case-sensitive` makes the match case-sensitive. Narrow with `--corpus`, `--package` or `--build-id` (each repeatable). `--count` returns an upper-bound estimate of candidate files first, no rows; a count is a trigram upper bound and the true match count is lower. `--limit` returns up to 200 rows per page; a page prints a `next:` line with the next cursor, `--cursor C` fetches the page at `C`, `--all` follows every page to the end (a 50-page cap, named in the output, then a narrow-the-query line), and `--out FILE.csv` writes every fetched row to a CSV (`package,corpus,path,line,text`) and implies `--all`; a capped `--out` names the cap in its summary. In the CSV, a snippet cell beginning with `=`, `+`, `@` or `-` is prefixed with a single quote (a spreadsheet formula-injection guard), so such a cell reads with a leading `'`. With `--all --json` the walk also stops at the 50-page cap and the last envelope's `page.next_cursor` is the resume point. A no-match, a timed-out estimate, a stale cursor, an unwritable `--out` file and an unavailable service each print the reason and a next action. Every page with more results prints `next: more results available; fetch them with --cursor C`, the first page too. A search with no match prints its cause and a next action: `no code matches "QUERY" in any indexed app` when every candidate file was scanned; `no match ... the search stopped at the time limit before every candidate file was scanned` (narrow with `--package` or `--corpus`, or raise `--time-limit-ms`, up to 30000); `no match ... in the part of the index that answered` when part of the index did not answer; `no more matches` for a `--cursor` past the last match. Too many searches from one account in a short time are refused with the wait in seconds and a next action (exit 6); `--all` and `--out` print a waiting line, wait that time and continue with the same page, up to 3 waits per page. Needs an atlas-enabled account. Never read or print the token.
